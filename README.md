# FFXIV Occult Crescent 自动化 SND 脚本合集（蜃景幻界新月岛）

本仓库收录 FF14「蜃景幻界新月岛」（英文 **Occult Crescent**，日文 蜃気楼の島 クレセントアイル）两份 SND（SomethingNeedDoing）Lua 脚本，均为纯 Lua 代码，可直接粘贴进 SND 运行：

* **北岛** = [The Occult Crescent: North Horn](https://ffxiv.consolegameswiki.com/wiki/The_Occult_Crescent:_North_Horn)（日服 北征編 / 国服 北征之章）
* **南岛** = [The Occult Crescent: South Horn](https://ffxiv.consolegameswiki.com/wiki/The_Occult_Crescent:_South_Horn)（日服 南征編 / 国服 南征之章）

| 脚本文件 | 用途 | 说明 |
| --- | --- | --- |
| [`北岛全自动FATE_CE兑换固定剂.lua`](./北岛全自动FATE_CE兑换固定剂.lua) | 自动无限重返北岛，刷 FATE / CE，白银币满 8000 自动回营地兑换终极固定剂 | 依赖 BOCCHI、vnavmesh、BossMod（BMR AI） |
| [`南岛22级怪群刷金币.lua`](./南岛22级怪群刷金币.lua) | 在南岛 22 级怪群附近定点刷怪刷金币 | 依赖 vnavmesh（寻路）与战斗插件（走位） |

> **不用下载文件**：直接在 GitHub 网页上点开对应的 `.lua` 文件，点代码区右上角的**复制按钮（Copy raw file）**把代码整段复制走，粘进 SND 并把 `Type` 选成 `Lua` 即可运行。文件本身就是纯代码，首尾没有 markdown 代码围栏，复制到的是干净代码，不需要手动删任何东西。

---

## 一、 前置插件准备

在运行脚本之前，请先确认你的 Dalamud 插件库里已经安装并启用了以下 4 个插件（缺一不可）：

* **SomethingNeedDoing**（简称 SND，用来运行本脚本的框架）
* **BOCCHI**（负责自动跑图找 FATE 与 CE）
* **BossMod**（负责战斗自动躲技能与位移）（或者用其他战斗插件，bm只负责走位）
* **vnavmesh**（负责全图寻路与营地自动导航）

---

## 二、 在 SND 中导入并运行脚本

1. **复制脚本代码**，两种方式任选其一：
   * **方式 A（推荐，免下载）**：在 GitHub 网页上点开你要用的 `.lua` 文件（例如 `北岛全自动FATE_CE兑换固定剂.lua`），点击代码区右上角的**复制按钮**，代码会整段进入剪贴板。文件是纯 Lua，不含 markdown 代码块标记，复制到的是干净代码。
   * **方式 B（本地文件）**：如果你已经把仓库下载到本地，用「记事本」或任意文本编辑器打开对应 `.lua` 文件，全选所有内容并复制。*（注：万一你的编辑器把开头/结尾显示成多出了 lua 代码围栏那两行（就是三个反引号那种），复制时跳过那两行，只复制中间纯代码即可。）*
2. **打开 SND 面板**：进入游戏后，在聊天框输入 **`/snd`** 并回车，打开 SomethingNeedDoing 窗口。
3. **新建脚本**：点击面板左上角的 **`+` 号**（或在左侧空白列表处右键新建），给脚本随便起个名字，比如 `新月岛全自动`。
4. **修改脚本类型（最关键一步）**：在右侧代码编辑区的上方，找到 **`Type`（类型）** 下拉框，把它从默认的 `Native` 切换成 **`Lua`**。*如果不改这一步，运行后会直接报错。*（两个 `.lua` 脚本都要这样选 `Lua`。）
5. **粘贴并启动**：把刚才复制的代码完整粘贴进编辑框里，然后点击编辑区顶部的**绿色播放（运行）按钮**，看到游戏聊天框跳出 `[新月岛守望] 最终版全自动挂机已启动...` 就说明跑起来了。

## 三、 挂机注意事项

* **推荐启动位置**：建议自己先传进**新月岛北岛**之后再点运行。脚本第一次在岛内启动时会自动记录当前地图 ID 并打印在聊天框里；如果你懂一点配置，也可以把聊天框报出来的那串数字填回代码最顶部的 `NORTH_HORN_MAP_ID = 0`（把 `0` 替换掉），这样以后就算站在岛外营地直接点启动，它也会自己找杰弗瑞传进去。
* **脚本会自动处理的事情**：进岛后自动开启 BMR AI 与 BOCCHI；角色发呆满 **40 秒**会先原地重启 BOCCHI（BMR AI 保持开启），重启后 **8 秒**仍未移动就用「返回」回起始营地重置（「返回」冷却中会再等 40 秒重试）；阵亡后若周围有活人会在喊话频道发一次 **`999`**，被好心人拉起来后自动喊一句 **`谢谢`**；**每 2.5 小时**（`EXCHANGE_INTERVAL_MIN = 150`）回营地找「调查队的古钱鉴定师」把白银币兑换成**终极固定剂**，币不够会自动提前停；满 3 小时被踢出岛后等 10 秒自动找杰弗瑞重新进岛。
* **如何手动停止**：想暂停挂机自己操作时，先在 SND 面板里点击**停止（方块）按钮**，然后自己在聊天框输入 **`/bocchiillegal off`** 和 **`/bmrai off`** 关掉两个插件的托管即可。

## 四、 南岛 22 级怪群刷金币脚本用法

这个脚本是独立的一份，配置区和上面那份北岛脚本完全分开，脚本顶部就能改：

* **`TARGET_LIST`**：要刷的怪名列表，默认是 `新月白焰`、`新月扎戈斧龙`、`新月哭泣鬼`。只认列表里的怪名，别把名字写错，否则脚本会一直原地扫描。
* **`ATTACK_RANGE`**：靠近怪时停步的距离，近战默认 `2.5`；远程 / 法系建议改成 `15 ~ 20`。
* **`PULL_SKILL`**：到位后的开怪技能，默认普攻 `自动攻击`，也可以换成 `飞刀`、`投盾` 一类的远程开怪技能。
* **`RETURN_DELAY` / `HOME_TOLERANCE`**：周围多久没怪（默认 `2.0` 秒）就走回起始点，以及离起始点多少米内算「已回原点」（默认 `2.0` 米）。
* **`CHASE_IN_COMBAT`**：进战后是否继续追怪，默认 `false`，把位移完全交给 BossMod 躲技能。

**使用要点**：

1. 站到南岛 22 级怪群附近的挂机点（脚下就是你想长期蹲的位置），再点运行。脚本启动时会打印并记住当前坐标作为起始点，之后没怪就往这里退。
2. 需要 `vnavmesh` 已就绪（脚本会等 `IsReady`），所以进图后先让插件加载完再启动。
3. 手动接管前先点 SND 的停止按钮；想彻底停掉自动走位可以顺手 `/vnav stop`。

## 五、 免责与反馈

* 两份脚本都只在 SND 的 Lua 环境里通过 `yield` 发送游戏指令、通过 `Svc` / `IPC` 查询状态，不注入进程、不改写游戏文件。
* 使用第三方插件与自动化脚本存在账号风险，请自行评估；建议先在小号或非关键角色上试跑。
* 脚本参数（怪名、坐标、菜单索引）与游戏版本、地区服语言相关，换环境后需要按注释自行校准。
